# LLM Pocket Lab

A mobile-first interactive companion for the Open LLM Engineering course. It
contains 14 concept cards, immediate-feedback quizzes, bookmarks, saved progress,
and installable iPhone Home Screen metadata.

## Run locally

```bash
npm install
npm run dev
```

Open the local network URL printed by Vite on an iPhone connected to the same
Wi-Fi network.

## Quality checks

```bash
npm run build
npm run lint
```

The design specification is saved at `design/mobile-concept.png`.
